Settings &
privacy

Nothing is scanned until you sign in to Canvas yourself and press the scan button.

01

Canvas website

Enter your school's official Canvas address. The browser will request access only for this exact website.

Examples: https://elearn.ucr.edu or https://school.instructure.com. HTTPS is required.

02

Optional Google Calendar

Calendar access is off by default. The extension never sees your Google password or saves your email address. If enabled, authorization tokens stay in this browser's local extension storage.

Google OAuth setup instructions
  1. Create or select a project in Google Cloud Console.
  2. Enable the Google Calendar API.
  3. Configure the OAuth consent screen for the intended users.
  4. Create a Web application OAuth Client ID.
  5. Add the redirect URL shown above to Authorized redirect URIs.
  6. Paste only the Client ID here. Never paste a client secret.

03

Announcement scanning

Seven days is recommended. Unchanged announcements are skipped unless the professor edits them.

04

Privacy controls

Assignments, announcement text, checklist history, settings, and optional Google tokens are stored only in this browser profile. There is no tracker account, analytics service, or shared database.
