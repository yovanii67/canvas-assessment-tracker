CANVAS ASSESSMENT TRACKER

Privacy Notice

Version 1 · September 23, 2026

Local-first operation

Scanned assignments, announcement text, Canvas event details, checklist status, settings, and acceptance history are stored in the browser profile where the extension is installed. The extension has no developer-operated account system, analytics service, or shared database.

Login information

The extension does not collect or save Canvas passwords or email addresses. You sign in manually on the official Canvas website, and the extension uses that browser session only after you press the scan button.

Optional Google Calendar

Calendar access is disabled by default. If you enable and authorize it, Google access and refresh tokens are stored locally so the connection can work. The extension does not store your Google password or email address. Approved task details are sent to Google only when you choose to create or update a Calendar event.

Website permissions

UCR Canvas access is included by default. For another school, the browser asks for access only to the exact HTTPS Canvas address saved in Settings. Google domain permissions are requested only when the user explicitly enables the optional Calendar connection.

Delete your data

Use Settings → Delete all local data to remove scanned coursework, task history, settings, acceptance history, and local Google authorization tokens from the browser.
