# Security Policy

Do not submit real passwords, OAuth tokens, Canvas cookies, private keys, course exports, student records, or screenshots containing private information in a GitHub issue.

For a suspected security problem, reproduce it with test data and share only the minimum technical detail needed. Rotate or revoke any credential that was accidentally exposed.

The extension intentionally uses no developer-operated backend. User data should remain in browser-managed local extension storage unless the user explicitly approves a Google Calendar event write.
