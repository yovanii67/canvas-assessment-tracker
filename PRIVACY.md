# Privacy Notice

Version 1 — September 23, 2026

Canvas Assessment Tracker is a local-first browser extension.

## Data stored locally

The extension may store scanned assignment details, announcement text, Canvas event details, checklist status, user-entered dates, settings, announcement fingerprints, terms acceptance, and optional Google authorization tokens in `chrome.storage.local`.

This data remains in the browser profile where the extension is installed. The project has no developer-operated backend, account system, analytics service, or shared database.

## Login information

The extension does not collect or save Canvas passwords or email addresses. Users sign in manually on their official Canvas website. A scan occurs only after the user presses the scan button.

## Optional Google Calendar

Calendar access is disabled by default. If enabled and authorized, Google access and refresh tokens are stored locally. The extension does not store the user's Google password or email address. Approved task information is sent to Google only when the user creates or updates a Calendar event.

## Website permissions

UCR Canvas is the default required host. A user may grant access to one additional exact HTTPS Canvas origin through Settings. Google host permissions are requested only when the user explicitly enables optional Calendar authorization and event creation.

## Deletion

Users can remove stored coursework, task history, settings, terms acceptance, and local Google tokens with **Settings → Delete all local data**. Removing the extension also removes its browser-managed local storage.
